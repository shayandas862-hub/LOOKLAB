# Look Lab — plans

Thoughts that are not yet decisions. One file per plan, named
`P-LL-NNN-short-title.md`, numbered from `docs/id-registry.json` (`allocated.plan`).
A plan that is adopted becomes a decision (`D-LL-*`) or an architecture decision
(`AD-LL-*`) that cites it; the plan file stays as the record of the thinking.
